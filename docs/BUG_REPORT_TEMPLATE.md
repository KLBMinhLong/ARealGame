# Mẫu báo lỗi

```text
Tiêu đề ngắn:
Engine (--version):
Hệ điều hành / RAM / GPU:
Commit hoặc version build:
Chạy từ editor hay bản export:
Các bước tái hiện (1, 2, 3):
Kỳ vọng:
Thực tế:
LỖI ĐẦU TIÊN, nguyên văn, file + dòng:
Log kèm theo (đã bỏ thông tin riêng nếu có):
Ảnh/video nếu cần:
Tái hiện luôn hay thỉnh thoảng:
Thay đổi ngay trước khi lỗi xuất hiện:
Mức độ: blocker / major / minor / cosmetic:
```

Đừng chỉ gửi “không chạy”. Đừng gửi API key, mật khẩu hoặc file save có thông tin riêng không liên quan. Ghi lỗi đầu trước khi agent sửa hàng loạt lỗi phụ.
