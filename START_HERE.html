03 / HOÀN THIỆN TỪNG LÁT CẮT

Một task. Một bằng chứng.

Duyệt kế hoạch → AI sửa → test → bạn chơi → commit. Không giao “làm tất cả rồi báo xong”.

Làm lần đầu trên máy bạn

Bản hướng dẫn đầy đủ ở START_HERE.md. Các bước dưới giả định Windows; không cần cài Python để chơi game.

1. Giải nén và chạy Godot
  1. Giải nén vào thư mục riêng, không đè project cũ. Root phải có project.godot, scenes/, scripts/.
  2. Godot Project Manager → Import → chọn project.godot → mở và chờ import xong.
  3. Bấm F5. Start Run, dùng WASD/mũi tên; Esc tạm dừng, R thử lại sau khi kết thúc. F8 dừng game từ editor.
  4. Nếu lỗi, copy lỗi đầu tiên ở Output/Debugger kèm file/dòng. Dùng prompts/03_FIX_BUG.md; không tạo lại project.
2. Cho Antigravity đọc đúng rules
  1. Mở chính root project trong IDE, không mở thư mục cha hoặc file ZIP.
  2. Bảng agent → … → Customizations → Rules. Chọn Workspace Rule 00-project, đặt Always On.
  3. Nếu IDE không nhận, tạo Workspace Rule qua UI, dán nội dung .agents/rules/00-project.md. Không ghi đè Global Rules.
  4. Chọn model có sẵn trong tài khoản. Chỉ cho quyền cần thiết trong project; giữ duyệt lệnh/thay đổi. Chưa tải asset hay gói trả tiền.

Tài liệu hiện dùng .agents/rules; hỗ trợ cũ .agent/rules. Kiểm tra UI nếu phiên bản IDE của bạn khác.

3. Chạy kiểm tra trước khi thêm feature

Lưu project, dừng game; nên đóng Godot editor trước headless import. Trong PowerShell ở root, thay đường dẫn ví dụ bằng exe thật:

& .\tools\verify.ps1 -GodotExe 'C:\DUONG_DAN_THAT\Godot_console.exe'

Không đổi policy toàn hệ thống nếu script bị chặn. Xem lệnh trực tiếp thay thế trong START_HERE.md. Cần đúng version, log không lỗi và marker ALL_TESTS_PASSED.

Test tự động không thay thế chơi thử. Bạn vẫn phải kiểm tra UI, phím, va chạm, pause, retry và bản export.

Prompt đầu tiên cho agent

Dùng sau khi mở đúng workspace. Agent chỉ kiểm tra baseline; nếu thiếu đường dẫn Godot, hãy cung cấp đường dẫn exe trên máy, không phải mật khẩu.

Hoặc chọn văn bản và Ctrl+C.

File nào dùng lúc nào?

AGENT_RULES.md
Giới hạn phạm vi, đọc wiring, bằng chứng kiểm thử và bảo vệ máy/tài khoản.
docs/GAME_BRIEF.md
Game làm gì, không làm gì; ý tưởng mặc định cần bạn duyệt.
docs/TECH_SPEC.md
Scene tree, input, signal, state và trách nhiệm từng script.
docs/TASKS.md
Task có dependency, acceptance test và trạng thái. Chọn một task mỗi phiên.
docs/TEST_PLAN.md
Kiểm thử tay và tự động; phân biệt viết test với thực sự chạy test.
prompts/
Khởi động, chọn task, triển khai, sửa bug, review, polish, export và bàn giao.
docs/RELEASE_CHECKLIST.md
Template đúng phiên bản, xuất Windows, đủ exe/PCK, license và cổng phát hành.

Điều bạn cần giữ quyền quyết định

AI có thể hỗ trợ phần lớn code, nhưng bạn vẫn quyết định game có vui không, chọn tài nguyên, duyệt chi phí, chơi thử và bấm phát hành. Game chạy được không tự chứng minh có người muốn mua.

Bộ này không kèm engine, export templates, tài khoản, executable Windows hay API key. Không tự động cài gì khi bạn mở trang HTML này.
